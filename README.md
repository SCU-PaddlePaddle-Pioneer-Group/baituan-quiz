# 飞桨领航百团大战趣味答题

供百团大战现场参与者使用的单选答题网页，共 20 题，每题 5 分。支持在线访问和本地打开，适用于活动现场的电脑和手机浏览器。

## 在线访问与部署

参与者使用现代浏览器联网访问：[打开答题网页](https://scu-paddlepaddle-pioneer-group.github.io/baituan-quiz/)。

维护者需要具有 [GitHub 仓库](https://github.com/SCU-PaddlePaddle-Pioneer-Group/baituan-quiz) 的管理权限。网站是纯静态页面，无需安装依赖或执行构建命令。

1. 在仓库的 `Settings → Pages` 中将 `Source` 设置为 `Deploy from a branch`。
2. 选择 `main` 分支、`/ (root)` 目录并保存。
3. 在仓库 `Actions` 中确认 `pages build and deployment` 工作流成功，再打开上述网址。

后续合并到 `main` 的修改会自动发布。`index.html` 与 `dist/` 必须一同保留；如访问返回 404，先检查 Pages 的分支和目录设置，再查看部署工作流日志。页面打开后应显示“开始答题”，浏览器网络面板中的 `dist/style.css`、`dist/questions.js`、`dist/quiz.js`、`dist/app.js` 应加载成功。

更新 `dist/questions.js` 后，同步将 `index.html` 中题库脚本地址的 `v` 参数改为新的版本标识，例如题库提交的短哈希，避免浏览器继续使用旧题库缓存。部署完成后刷新网页，作答到相应题号，确认题干和选项与题库一致；若仍显示旧内容，强制刷新页面后重试。

代码与题库随公开仓库发布。在线版本沿用下文的内存计分规则，不上传参与者的答案或成绩。

## 打开网页

前置条件：使用现代浏览器，无需安装依赖或连接互联网。

1. 双击本目录最外层的 `index.html`，在浏览器中打开。`dist/` 文件夹存放样式、脚本和题库，需要与 `index.html` 一起保留。
2. 点击“开始答题”，每页选择一个选项；在当前页可点击其他选项切换选择，确认蓝色边框标记的选择后点击“下一题”。
3. 完成第 20 题后点击“查看总成绩”。

也可以在本目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。按 `Ctrl+C` 停止服务。若端口被占用，可更换端口。

## 成绩与返回

当前题可以反复切换选项，点击“下一题”后固定该题的选择。最后一题在点击“查看总成绩”前也可改选，总分按每题的最新选择计算，每道题最多计 5 分。所选选项统一显示蓝色边框，不提示对错。答题、返回后继续答题及成绩页面均不展示正确答案或解析；完成全部题目后仅显示总分与答对题数。

页面只在内存中保留最近一位已完成答题者的总成绩，不写入文件、浏览器存储或服务器。返回首页、开始下一人答题后仍可在首页查看上一人成绩；刷新或关闭页面会清除所有答题状态。未完成答题的记录不会覆盖已完成的成绩。浏览器返回按钮会回到首页，进行中的答题可通过“继续答题”恢复。

## 验证

运行 `node --test quiz.test.cjs` 检查题目完整性、当前题改选、计分、返回恢复、上一人成绩，以及 20 题全流程的页面内容和无障碍标签不展示答案。手动打开网页，在同一题先后点击不同选项，确认蓝色边框移至最新选项、没有对错提示或解析；最后一题改选后查看总成绩，应按最新选择计分。返回首页后继续答题、查看本人成绩和上一人成绩时也不应出现答案。

第 19 题依据[飞桨官方介绍](https://github.com/PaddlePaddle/Paddle/blob/develop/README_cn.md)；第 20 题的社团性质采用活动组织者提供的表述。
